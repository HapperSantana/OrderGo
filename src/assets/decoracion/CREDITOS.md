# Créditos y licencias de las imágenes decorativas (CC13)

Estas imágenes se usan solo como decoración en los bordes de las pantallas internas
(`src/components/ui/Decoracion.tsx`). Todas son SVG livianos, sin fotos incrustadas, sin
scripts y sin referencias externas (lo verifica `npm test`).

| Archivo | Origen | Licencia |
|---|---|---|
| `vaso-cola.svg` | "Soda" de GDJ (OpenClipart 311979), descargado de SVG Repo | **CC0 / dominio público** (declarado en el propio archivo) |
| `ensalada.svg` | SVG Repo | **Por confirmar** (el archivo no declara licencia) |
| `plato-vegetales.svg` | SVG Repo | **Por confirmar** (el archivo no declara licencia) |
| `plato-verduras.svg` | SVG Repo | **Por confirmar** (el archivo no declara licencia) |
| `caja-jugo.svg` | SVG Repo | **Por confirmar** (el archivo no declara licencia) |
| `hoja.svg`, `mancha.svg` | Dibujadas para OrderGo | Propias del proyecto |

**Pendiente:** en SVG Repo cada ícono tiene su propia licencia (algunas exigen dar crédito
al autor). Antes de publicar la aplicación, abre la página de cada ícono en
<https://www.svgrepo.com>, confirma su licencia y, si pide atribución, anótala aquí y en la
aplicación.

Los archivos se conservan tal como se descargaron (no se modificaron sus colores ni su
contenido). Los colores propios del proyecto se aplican solo a `hoja.svg` y `mancha.svg`.
